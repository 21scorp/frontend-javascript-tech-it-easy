# COVE — full asset prompt list (Style 1: hand-painted cozy)

The chosen style. Every prompt below is complete — copy, paste, generate,
save the result as the exact filename shown, drop it into
`cove/assets/sprites/`, done. The game picks it up automatically.

Tips for a consistent set:
- Use the **same seed / style reference** across all prompts if your tool
  supports it. Generate the whole set in one session.
- If the tool can't output transparency, generate on a plain solid
  background and use its background remover (or remove.bg).
- Judge every result at ~15% size — sprites live small.
